Original 1K JPEG maps; no third-party logos, faces or characters.
Unity imports the normal maps as linear normal data and uses mipmaps and Android
ASTC 6x6 compression. Linen uses the scene's own color and the scanned normal map.
The downloads are runtime source assets and must not be deleted as cache.
